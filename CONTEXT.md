# NODEINE

An artwork-first archive and creator network organized around authored visual Worlds.

## Language

**World**:
A creator's collection of related artwork and films, with its own identity and optional authored Threads.
_Avoid_: Treating every visually similar piece as part of the same World.

**Thread**:
A creator-authored, ordered connection between existing pieces. It expresses an intentional relationship rather than inferred visual similarity.

**Discussion**:
Public comments about an artwork, including general observations and pinpoint feedback.

**Pinpoint feedback**:
A comment referring to a selected location in an image. The reference marker is an optional viewing aid, not a modification to the artwork.
_Avoid_: Annotations burned into the original image.

**Feedback mode**:
An explicit view for reading, selecting and placing pinpoint feedback. Ordinary artwork viewing does not display its markers.

**New since last visit**:
Artwork newly encountered in a World compared with a previous visit. It is distinct from unread messages, notifications or proof that every piece was viewed.
