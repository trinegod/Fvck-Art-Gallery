## Useful lesson, not copied artwork

Inference: a reveal is strongest when motion explains or resolves into a recognizable static mark, with clear contrast and room around it. The transferable idea is choreography and hierarchy—not the creator's lamp motif, client symbols, letterforms or compositions. A browser animation can use original SVG paths and CSS transforms/opacity; it does not inherently require the separate Three.js combat engine.

For NODEINE, the implemented **World Aperture** already provides an original name-independent mark. Keep its existing pending-state orbit for actual loading. A later optional launch study could draw the world arcs, settle the aperture and reveal the current wordmark once. An initial 300–600 ms design target would be a hypothesis to test, not a requirement or measured property of the reel. If content is ready, show it immediately; if motion is reduced, show the static mark. Do not make users sit through a miniature advertisement every time they open Messages.

## Portable proposals, not implemented changes

- **NODEINE:** a brief, optional identity reveal at a genuine entry boundary; ordinary chat/feed loads retain useful shells and honest status.
- **108 Yokai — Fourth Portal:** a richer original ink/ritual entrance with visible Skip and static poster, isolated from navigation and content loading.
- **Trinefield:** a portfolio hero or project-transition demonstration where a visitor deliberately chooses to play the animation. Résumé, work and contact remain available without it.
- **Biao:** a restrained brush/line accent near meaningful content. Keep text readable/selectable and avoid slowing a frequent operational task with repeated intros.

## Before producing a finished reveal

Choose the stable mark first, then define duration, size, entry/repeat rules, static fallback and accessibility behavior. Test narrow phones, low-power devices, reduced motion, interrupted navigation and immediate cached loads. Use owned/cleared assets and preserve licenses for any borrowed implementation. The current NODEINE loading implementation is original UI code, not a copy of this reel.
