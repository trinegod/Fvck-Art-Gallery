# Triage labels

| Role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | Waiting for missing information. |
| `ready-for-agent` | Fully specified and ready for an AI agent. |
| `ready-for-human` | Requires human implementation. |
| `wontfix` | Reviewed and intentionally not pursued. |

Use these exact strings when a skill names a triage role. Read existing labels
before creating any; do not duplicate an existing label or reclassify unrelated issues.
